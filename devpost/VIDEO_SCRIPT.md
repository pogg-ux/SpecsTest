# MWNP No-Guess Field Assistant — Demo Video Script (target 2:45)

Record: Lens Studio Preview, Multimedia backdrop, Win+Alt+R. Mouse = pinch. Scroll-zoom in on cards when reading matters.
Rule: the Lens is working in the first 10 seconds.

---

**0:00–0:10 — Cold open (Lens already running)**
SCREEN: Step card + traced wire already showing; enter 0.0 at F1 OUT → F1 turns red, "F1 open" appears.
VO: "Actuator won't extend. My glasses just found the open fuse — and it never guessed."

**0:10–0:25 — The problem**
SCREEN: Slow pull back over the cabinet.
VO: "I'm an industrial machine tech. On a service call, I'm juggling a meter, a printed schematic and a manual — eyes off the machine every few seconds. This puts the schematic on the machine."

**0:25–0:40 — Start + Library**
SCREEN: Reset. Safety notice → Dismiss → Library menu (upper left).
VO: "It opens with a safety reminder, then the Library menu up in the corner: job, report, camera, options — and it folds away when I don't need it. The job files are loaded before I start — the wiring and tolerances for this machine."

**0:40–1:05 — Symptom → path**
SCREEN: Job → Report symptom → "EXTEND doesn't work". Outlines + trace appear. Zoom on step card citation.
VO: "I report the symptom. It reasons from the schematic: RETRACT works, so power and the switch are good. The EXTEND path is wire 2a, terminal 4, wire 2b, fuse F1, 2c, lamp L1. It outlines those parts and traces the run."

**1:05–1:20 — Schematic**
SCREEN: Tap Schematic → zoomed, labeled, wire 2b highlighted.
VO: "If I want the print, it shows just the section I need, with the wire I'm chasing."

**1:20–1:50 — Readings**
SCREEN: Enter 12.1 at TS-4 (green), 12.0 at F1 IN (green), 0.0 at F1 OUT (red).
VO: "I enter what my meter actually reads. Each test point has its own tolerance from the job file — twelve volts plus or minus ten percent for these lamps. Twelve-one, good. Twelve at the fuse input, good. Zero at the output."

**1:50–2:05 — Finding**
SCREEN: Finding card, zoom on "F1 open" + next action.
VO: "F1 is open. It tells me exactly what to do: lock out, check continuity, replace with the same half-amp fast-blow — don't upsize."

**2:05–2:20 — No-guess**
SCREEN: (Fresh run or prepared) enter 6.0 at F1 OUT → amber message.
VO: "And if a reading doesn't fit anything in the files — six volts here — it doesn't make something up. It tells me to recheck my leads."

**2:20–2:35 — Retest + report + hide**
SCREEN: Fuse replaced: retest → S1 UP → L1 lights → 12.0 green → Job report. Then Hide → labels stay → Show.
SCREEN (add): Notes → Add note → "Fuse replaced"; Job → End job → Yes; Job report shows "Complete".
VO: "Retest, lamp's on, logged. I add a note, end the job, and the report has every reading, note and time. And when I need to work, one tap clears the cards and keeps the labels on the parts."

**2:35–2:45 — Close**
SCREEN: Full view of the cabinet with labels. (Optional: 3-second clip of the real MWNP 1.0 bench unit.)
VO: "Rule-based, so it never invents an answer. Next: live part recognition, manual lookup and job history. MWNP No-Guess Field Assistant."

Checklist before recording: Options = Normal text, Translucent cards; Preview reset; window maximized; mic test; no personal info on screen.
